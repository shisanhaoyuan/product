# 商品库图片与 Amazon 配送地区

## 商品库图片

导入自数字酋长的图片可能因 CDN 所在节点或访问网络不同，出现 `MirrorFailed` / 403 / 424。
商品卡片、表格及档案图片现在先经过本系统的商品图片缓存接口。接口只接受当前商品或其子变体已经记录的指定 CDN 图片；下载时继续检查域名、重定向、文件大小和图片格式。

第一次成功读取后，图片保存到现有图片存储，并记录与商品 / SKU 的对应关系。后续优先读取本地副本，不依赖原始 CDN。显示缓存不会更改原始导入记录或人工选择的图片。如果服务器也无法下载，仍需要在商品档案中按 ASIN 重新抓取或上传图片；不能恢复从未保存且所有来源均已失效的图片。

## 配送地区人工接续

1. 更新服务器代码并构建前端：在 `/www/wwwroot/jiwu` 执行 `bash deploy/update-git.sh`。
2. 在来源采集区下载当前版本的集物采集插件（与数据接入、图片补采及预上架共用同一个下载包），替换原扩展文件，在 Chrome / Edge 扩展管理中重新加载。按安装说明连接商品库并刷新网页。
3. 后台无法确认邮编 10001 时，前端会通过助手打开 Amazon。也可点击“打开浏览器设置地区并采集”。在 Amazon 左上角手动设置配送邮编 10001，确认完成后自动继续。
4. 助手只在页面显示 10001 且 ASIN 匹配时返回报价。普通浏览器自身保留 Cookie，助手不导出、不上传 Cookie。
5. 成功后启用“后续使用本机浏览器（保留地区）”；可以取消勾选切回后台。此偏好仅对当前浏览器中的商品库有效。关闭浏览器无痕窗口、清除 Cookie、切换电脑或 Amazon 重置会话，都可能要求重新设置。

本机浏览器和服务器浏览器独立保存状态，人工配置本机不会修改服务器 Cookie。后台浏览器现在也使用专用持久目录：当已配置 `CATALOG_AMAZON_BROWSER_CACHE` 时，默认使用其同级 `profile` 目录，可用 `CATALOG_AMAZON_BROWSER_PROFILE` 覆盖。目录权限为 700，使用文件锁阻止跨进程并发占用。现有服务器配置无需重装 Camoufox。

地区设置失败但 ASIN 已核验时，后台仍可返回并保存图片；非 10001 的报价不会补入商品来源价格。

## 反向代理等待时间

后台浏览器最长等待 240 秒，HTTPS 站点的 `proxy_read_timeout` 和 `proxy_send_timeout` 应至少为 300 秒。宝塔生成的线上配置不随 Git 更新改变；本项目现有 HTTPS 配置是 `/www/server/panel/vhost/nginx/jiwu_https.conf`。修改前备份，修改后执行 `nginx -t`，成功再 `nginx -s reload`。不要替换其他站点的全局代理配置。
