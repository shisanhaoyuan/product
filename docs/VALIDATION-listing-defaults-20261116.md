# 商品信息自动选择 — 2026-11-16

- 商品资料返回同一 listing_id 的来源类目；旧批次缺少类目提示时只读补充，不改来源商品或批次价格。
- 前端在官方类目、目标店铺启用仓返回后补空项：来源完整类目或末级类目与唯一官方类型匹配时选择真实选项；忽略大小写及多余空白。没有匹配或有歧义时保留空白，不能把供应商类目直接当作官方选项。
- 只有一个启用仓时自动填写该仓。多个仓时保留选择；不会使用供应商分仓或写死截图中的仓号。
- 自动选择按每一行的 listing_id 进行，保护已选类型、已选仓、编码与豁免配置及正在处理/已成功的行；沿用资料保存接口落盘。当前商品类型的官方字段由原有加载流程获取。
- 新建资料没有编码时默认 EAN；已有12位UPC、13位EAN及其他真实编码沿用原识别规则，保留前导零。不生成编码，不改变价格、库存或文案。
