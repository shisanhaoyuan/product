# 大建云仓商品预上架

在「大建云仓」商品库筛选或批量搜索 SKU，勾选本页商品或选择跨页筛选结果，点击「预上架」。商品详情也提供「预上架此商品」。仅管理员、编辑员或本机单人模式可操作。

选择目标店铺、品牌和本次倍率后生成预览，再创建待上架批次。每批最多 500 件；确认批次仍不会向沃尔玛提交商品，正式刊登接口尚未接入。

云仓按供应商 SKU 区分商品，无需 ASIN，不把组合配件自动当作子变体。同一来源 SKU 在同一目标店铺的未取消批次中不可重复；允许预上架到不同店铺，并分配各自唯一的 `MY＋两位店铺编码＋六位字母数字` 平台 SKU。取消批次后再创建会复用该店铺既有的平台 SKU。

## 计价和库存

- 价格基准：原始 API 快照的普通商品单价＋物流费（含打包费），再乘本次倍率，四舍五入到两位小数。不使用优惠价，不重复加打包费，不对本地已经调整过的售价再次乘倍率。例如 `(67＋2.33)×1.15＝79.73`。
- 仅接受 USD；缺价、缺运费、物流区间或 SKU 不对应时记录待复核，不猜测免运费，也不擅自选择区间端点。
- 取原始 API 的 Seller 可售库存：小于 10 时预上架库存为 0，大于或等于 10 时为 10；未知库存保持未知。预上架库存为 0 的商品保留待复核草稿，不能确认。
- MSRP 为预上架售价的两倍。原始普通单价、物流费、总库存和分仓原始资料保留在批次与来源快照中，不覆盖商品库。

## 内容与复核

批次冻结商品库中当前的图片、标题、卖点、描述、商品编码及属性，并保留原始 API 来源价格、库存和分仓资料。允许本地编辑后的文案进入批次，不伪称完成 ERP 回读。缺少图片、有效标题、描述、卖点、商品编码或来源类目，或供应商明确标记 SKU 不可用时显示中文待复核原因。

此处只是本系统的预检查；来源类目并不等同于沃尔玛类目，UPC / GTIN 真实性及豁免、品牌、图片和具体类目必填项仍需在正式提交功能中按官方 Schema 验证。

来源更新、库存价格巡查、本地编辑、卖家黑名单或目标店铺改变后，确认时重新生成预览并检查快照；不一致则阻止旧批次确认，需取消并重新创建。所有预上架操作不改写来源商品信息、不刊登。
