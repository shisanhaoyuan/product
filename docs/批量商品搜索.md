# 批量搜索商品

亚马逊商品库、大建云仓商品库和待复核列表共用原有搜索框，支持普通关键词和批量编号，无需单独窗口。

1. 直接在搜索框输入多个 SKU / ASIN，或粘贴多行编号；也可用逗号、空格、分号、顿号分隔。
2. 系统忽略大小写、自动去重，一次最多 100 个不同编号，总文本不超过 6000 字符，单个编号不超过 200 字符。
3. 输入停止后自动搜索，按回车立即搜索。匹配任意一个编号；命中多个编号的同一商品只显示一次。

完整匹配商品 SKU、商品平台 SKU、父 ASIN、子变体 SKU 和子 ASIN，不匹配标题、卖家中的相似文字或编号前缀。命中子变体时返回所属商品，详情与预上架仍保留该商品全部变体，不因搜索自动删减子 SKU。

纯字母 SKU 请用逗号、分号或换行分隔；空格分隔时，编号须含数字或连字符等编号特征，以保留普通商品名称和卖家关键词搜索。多行粘贴会在原搜索框显示为逗号分隔的列表，不弹出窗口。

搜索框识别为批量编号时使用精确匹配，否则沿用普通关键词搜索；两种搜索切换时清除另一种条件并回到第一页，保留当前来源库、类目、店铺、品牌、日期、状态等其他筛选条件。分页、导出清单、跨页全选及预上架预览使用相同的匹配条件。直接编辑搜索框可修改编号，清空搜索框可清除搜索。零匹配时显示空结果，不回退到全库。

本功能只读取数据，不修改商品 ASIN、SKU、价格、库存、图片或文案，也不会提交刊登。
