# 沃尔玛美国站店铺绑定

入口：顶部「店铺管理」→「沃尔玛绑定」（`/#/walmart-accounts`）；「店铺资料」用于维护系统店铺和 SKU 编码。团队模式只有管理员能查看和操作绑定模块；编辑员、只读成员直接请求 API 也会被拒绝。本机模式沿用本项目单人信任模式，仅限回环地址使用。

## 本次范围

可为每个系统店铺绑定自己的 Walmart US 个人 API 密钥，验证连接、读取实际店铺身份及权限、更新密钥、解绑。没有接入商品提交、Feed、订单或库存写入。本模块的“验证通过”只表示最近一次凭证和身份验证成功，不代表已正式刊登或一定具有全部刊登权限。

验证流程：输入凭证 → 官方 Token API → Token Detail → Partner Profile → 展示沃尔玛实际店铺名称和 Partner ID → 管理员勾选确认 → 保存绑定。只保留必要身份字段，不保存税号、完整平台响应或访问令牌。预览 10 分钟有效、限定创建管理员与系统店铺；使用数据库版本检查，绑定／解绑并发时旧操作无法覆盖新结果。

每个沃尔玛 Partner ID 只能绑定一家系统店铺。同一家系统店铺更换密钥必须仍属于原 Partner ID；如果真的要改绑另一个卖家账号，需先解绑并重新核对。解绑删除本系统凭证和未确认预览，不撤销沃尔玛后台密钥、不删除平台商品；数据库历史备份不随解绑改写。

## 只需一次的主密钥初始化

所有店铺共享一份服务器加密主密钥，不需要每家店铺配置环境变量。店铺 Client ID 和 Client Secret 从 HTTPS 网页输入，只以 AES-256-GCM 密文保存在数据库中，并将密文绑定到系统店铺 ID，防止复制密文后跨店使用。主密钥不在数据库中，不提交 Git；接口只返回 Client ID 尾号，不返回完整凭证。

服务器更新代码和依赖后，以 root 执行：

```bash
bash /www/wwwroot/jiwu/deploy/init-walmart-vault.sh
```

脚本创建 `/www/server/jiwu-data/walmart-credentials.key`（仅 jiwu 服务账号可读取），在 `/etc/jiwu.env` 增加一条主密钥路径，检查权限并重启 jiwu。已存在的主密钥不会被覆盖；数据库已有凭证但主密钥缺失时会停止，必须恢复原密钥。初始化不需要填写任何店铺 API 密钥。

本机默认路径为项目 `data/walmart-credentials.key`，执行：

```bash
python -m catalog.credential_vault init
```

自定义路径使用 `CATALOG_CREDENTIAL_KEY_FILE`，然后重启服务。没有主密钥时系统正常运行，但绑定与验证入口提示初始化；解绑仍可使用。

**备份与迁移**：现有数据库备份包含加密后的绑定记录，JSON 商品导出不包含凭证。现有 `deploy/backup.sh` 只备份数据库和图片，不备份主密钥。必须另行安全保存原主密钥；恢复或迁移数据库时同时恢复对应主密钥，权限设为 600，所有者为服务账号，核对界面/API 的 key_id。失去主密钥将无法解密，只能重新绑定各店铺。不要直接生成新密钥覆盖旧文件；密钥轮换迁移不在本期范围。

## 店铺绑定操作

1. 添加或选择系统店铺（先维护名称和 SKU 编码）。
2. 点击“绑定店铺”，填写该店铺 Seller Center → API Integration → API Key Management 的个人 Client ID、Client Secret。
3. 点击“验证密钥并读取店铺”。检查返回名称、Partner ID、Store ID，确认美国站。
4. 勾选账号与系统店铺对应关系，点击“确认绑定”。
5. 更换密钥采用相同的验证和确认流程；任何验证失败都不会替换旧凭证。
6. “重新验证”会更新上次验证时间、权限和状态。网络失败、权限不足或身份不符显示中文错误并保留原凭证，供修复后重试。

密钥输入框不回显，不存入 localStorage、sessionStorage；验证结束／窗口关闭会清空。权限和错误按白名单保存，远端错误正文不会回显。操作审计只保存操作者、时间、动作和安全错误说明。访问令牌只在单次验证调用内存中使用。

## 官方接口依据

- https://developer.walmart.com/us-marketplace/docs/get-started-as-a-seller
- https://developer.walmart.com/us-marketplace/reference/tokenapi
- https://developer.walmart.com/us-marketplace/reference/gettokendetail
- https://developer.walmart.com/us-marketplace/reference/getpartnerconfigurations

固定请求 `https://marketplace.walmartapis.com`：`POST /v3/token`、`GET /v3/token/detail`、`GET /v3/settings/partnerprofile`。禁用 HTTP 重定向与环境代理，不支持由浏览器指定 API 主机。未使用真实店铺密钥时，只能验证模拟接口行为，不能宣称实际授权已接通。
